# Galaxy S9 (SM-G960N) Rooting Guide — Rooting Branch

갤럭시 S9 **SM-G960N**(국내판) 루팅 과정을 정리한 저장소입니다.  
이 문서는 **본인 소유 기기**를 대상으로, 개발/연구/테스트 목적에서 루팅을 진행할 때 필요한 절차와 체크리스트를 제공합니다.

> ⚠️ 주의 / 면책
> - 루팅 및 부트로더/펌웨어 변경은 **제조사 보증 무효**, **KNOX 트립(영구)**, **삼성페이/보안 폴더 등 일부 기능 제한**이 발생할 수 있습니다.
> - 진행 중 데이터가 삭제될 수 있으니 반드시 **백업**하세요.
> - 이 문서는 **FRP 우회, 잠금 해제 우회, 도난 기기 접근** 등 불법·비인가 행위를 다루지 않습니다.

---

## 지원 기기

- ✅ Samsung Galaxy S9 (SM-G960N)
- ✅ Android 버전/보안 패치에 따라 파일/절차가 달라질 수 있음 (아래 “사전 확인” 필수)

---

## 이 브랜치 목표

- 공식 펌웨어 기반으로 **부트 이미지 패치(Magisk)** 후
- **Odin 플래시**를 통해 루팅 적용
- 루팅 이후 기본 점검(루트 권한, SELinux, SafetyNet/Play Integrity 상태 확인 등)까지 정리

---

## 사전 준비물

### 1) PC 환경
- Windows 권장 (Odin 사용)
- Samsung USB Driver 설치
- Odin (권장 버전은 `tools/` 또는 Releases 참고)
- ADB/Fastboot (플랫폼 도구)

### 2) 스마트폰 설정
- **개발자 옵션 활성화**
  - 설정 → 휴대전화 정보 → 소프트웨어 정보 → “빌드번호” 7회 탭
- 개발자 옵션에서:
  - **OEM 잠금 해제(OEM Unlock)** 활성화
  - **USB 디버깅** 활성화

> OEM 잠금 해제가 보이지 않으면:
> - 기기를 인터넷에 연결하고, 삼성/구글 계정 로그인 상태로 일정 시간(통상 7일 전후) 유지해야 표시되는 경우가 있습니다.
> - 이 저장소는 “표시되지 않는 OEM Unlock을 강제로 우회” 같은 방법을 제공하지 않습니다.

### 3) 데이터 백업
- 내부 저장소(사진/문서), 앱 데이터, 연락처 등 백업
- 루팅 과정에서 **공장 초기화(데이터 wipe)** 가 발생할 수 있습니다.

## 사전 확인 (매우 중요)

아래 정보를 먼저 확보하세요.

- 모델명: **SM-G960N**
- 현재 펌웨어/빌드: 설정 → 휴대전화 정보 → 소프트웨어 정보
- CSC/통신사: 예) KTC / SKC / LUC 등
- 보안 패치 수준: 예) 202x-xx-xx

**권장 원칙:**  
현재 기기와 동일한 빌드/보안 패치의 **공식 펌웨어**를 사용하세요.  
(서로 다른 빌드 조합은 부팅 실패/무한 재부팅 위험이 커집니다.)

---

## 전체 흐름 요약

1. 공식 펌웨어 확보 (AP/BL/CP/CSC)
2. 펌웨어에서 `AP` 추출 → `boot.img`(또는 `AP` 내 부트 관련 이미지) 확인
3. Magisk로 부트 이미지 패치 → `magisk_patched.tar` 생성
4. Download Mode 진입
5. Odin으로 패치된 이미지 플래시
6. 첫 부팅/초기 설정 후 Magisk 앱에서 루트 확인
7. 루팅 후 점검 및 안정화(모듈/최적화/백업)
